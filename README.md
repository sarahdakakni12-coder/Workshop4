# Tableau Workshop 4

## Overview
This workshop focuses on using Tableau to analyze data and create visualizations. It includes a line graph for life expectancy across different countries and an analysis of IT ticket processing performance using calculated fields and a target parameter.

## Projects

### Part 2 – Question 1: Life Expectancy Line Graph
**File:** `WS4-P2Q1-SarahDakakni.twbx`

- Created a line graph to explore life expectancy trends over time.
- Compared data across Australia, Canada, France, Germany, Japan, the United Kingdom, and the United States.
- Used Tableau to visualize changes over time and compare countries.

### Part 3 – Question 2: IT Ticket Processing
**File:** `WS4-P3Q2-SarahDakakni.twbx`

- Analyzed IT ticket processing performance by location.
- Created a calculated field to measure the percentage of tickets processed.
- Used a target parameter of 80% to evaluate performance against the target.
- Created a calculated field to identify whether the processing percentage exceeded the target.
